Your pocket document studio

1. Import images or open the camera.
2. Select a page from the thumbnail strip.
3. Crop: drag all four corners to the document edges, then apply.
4. Choose a filter and adjust brightness or contrast.
5. Reorder pages and download a PDF.

Saving and camera access

Save project downloads a JSON file with original images and edits. Open it later to continue. There is no automatic cloud backup. Browser camera access requires a secure context and permission; mobile camera upload is available as a fallback. Large images are resized to a maximum 2400 pixels on their longest side.

Version 1 scope

Image scanning, manual perspective correction, rotation, filters, multipage export, print and editable project files. No OCR, PDF import, automatic document detection or cloud sync yet.
